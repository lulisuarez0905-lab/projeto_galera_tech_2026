# projeto_galera_tech_2026

O Projeto Web consiste no desenvolvimento de um sistema de inscrições online, solicitado pela Galera Tech, com a finalidade de facilitar, organizar e tornar mais ágil o processo de cadastramento de novos participantes. A proposta surgiu a partir da necessidade de oferecer uma alternativa mais prática e eficiente para a coleta de informações, reduzindo etapas manuais e centralizando os dados em um único ambiente digital.

Através de um formulário estruturado, o sistema permite que os interessados preencham suas informações pessoais e forneçam os dados necessários para realizar a inscrição. Além disso, busca proporcionar uma experiência simples e intuitiva, permitindo que o preenchimento seja realizado de maneira organizada, sem exigir conhecimentos técnicos por parte do usuário.

Para o desenvolvimento da aplicação, foram utilizadas diferentes tecnologias, cada uma desempenhando uma função específica dentro do sistema. O HTML foi responsável pela estruturação dos elementos da página, enquanto o CSS foi utilizado para desenvolver a identidade visual e a organização dos componentes. O JavaScript complementa a aplicação com funcionalidades interativas, validações e recursos que auxiliam durante o preenchimento do formulário.

Na parte de processamento e gerenciamento das informações, foi utilizado o PHP, responsável por receber e tratar os dados enviados pelo formulário, além de estabelecer a comunicação com o banco de dados. O SQL, por sua vez, é utilizado para organizar, consultar e armazenar as informações, garantindo que os dados das inscrições possam ser mantidos de maneira estruturada.

Dessa forma, o projeto reúne conhecimentos de desenvolvimento Front-end e Back-end, integrando diferentes linguagens e tecnologias para construir uma aplicação funcional. Mais do que desenvolver um formulário, o objetivo é entregar à Galera Tech uma ferramenta que contribua para a melhoria de seus processos internos, proporcionando maior praticidade tanto para os candidatos quanto para os responsáveis pelo gerenciamento das inscrições.
